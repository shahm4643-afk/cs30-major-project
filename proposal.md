# Proposal

## Description

I am going to make a Formula 1 Racing game. You will be able to race in different circuits and different teams. Each team will have their strengths and weaknesses.

## Needs to Have List

- Website Integration: Integrate the racing game into my existing Formula 1 website.

- Multiple Circuits: Create multiple Formula 1 circuits using 2D arrays and JSON files. Each circuit will have its own layout and design.

- Driver Selection: Allow players to choose which driver they want to race as. Also allow players to choose which ever circuit they want to race on.

- Team Selection: Give players the option to choose different Formula 1 teams, each with its own strengths and weaknesses.

- Team Performance: Give each team different car statistics, such as acceleration, top speed, and handling.

- Website Design: Improve the website's appearance and layout using HTML and CSS so the game feels like part of a complete website.

- Personal Records: Save each player's best lap time for every circuit so they can track their own progress.

- Global Rankings: Display the top 3 fastest players on each circuit, including their usernames, teams, and lap times.


## Nice to Have List

- Multiplayer: Allow players to compete against each other using P5party which they can join each other's games with a code.

- Six-Player Races: Allow up to six players or cars to compete in the same race.

- Tyre System: Add different tyre compounds, such as soft, medium, and hard, with different levels of grip and durability.

- Car Damage: Add a damage system where collisions can affect the car's performance.

- Custom Race Settings: Allow players to change the number of laps, difficulty, and other race settings.

- Leaderboards: Display the fastest lap times and best race results.

- Global Leaderboards: Store the fastest lap times for every circuit in an online database. Whenever someone completes a lap, their time is compared with the existing records. Players from anywhere in the world can view the fastest times on each track and compete to become the global record holder.
